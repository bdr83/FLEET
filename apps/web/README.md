# apps/web — لوحة التحكم (Next.js)

لوحة تحكم عربية من اليمين لليسار فوق واجهات `apps/api`. المرجع البصري: النموذج الأولي من المرحلة B.

## التشغيل محليًا

```bash
# الخادم (apps/api) يعمل على 3000 مع OTP_DEV_ECHO=1 في التطوير
# الموقع يدخل بالبريد وكلمة المرور؛ LOGIN_PHONE=1 يظهر الدخول برقم الجوال (اختبارات e2e تحتاجه)
cd apps/web && npm install
API_URL=http://localhost:3000 npm run dev      # http://localhost:3001
```

## الأمان (BFF)

- المتصفح لا يرى رموز الدخول أبدًا: `/api/session/*` و`/api/v1/*` في Next تحفظها في cookies من نوع httpOnly + SameSite=Lax
  (`fp_at` 14 دقيقة، `fp_rt` 30 يومًا، `fp_ut` رمز المستخدم قبل اختيار الشركة 9 دقائق).
- كل طلب غير GET يحتاج الترويسة `x-fp-csrf: 1` وإلا يُرفض (403).
- تجديد الجلسة يتم في الخادم مع منع التجديد المتزامن المكرر داخل العملية. عند التشغيل على أكثر من نسخة
  يلزم Redis أو sticky sessions لأن إعادة استخدام refresh token تُلغي الجلسة كلها [تخمين: يُحسم عند النشر].

## الشاشات

| الشاشة | المسار | الحالة |
|---|---|---|
| الدخول بالجوال والرمز، اختيار الشركة أو إنشاؤها | `/login` | ✓ |
| لوحة التوزيع (أرقام اليوم، قائمة الانتظار مع الإسناد السريع، السائقون) | `/` | ✓ |
| المهام: قائمة وبحث وفلاتر وإنشاء | `/tasks` | ✓ |
| تفاصيل المهمة والسجل والإجراءات (نشر، إسناد، إلغاء إسناد، إلغاء بسبب، مراجعة، إعادة) | `/tasks/[id]` | ✓ |
| المركبات: قائمة وفلاتر وإضافة وتعديل والحالة ووثائق كل مركبة | `/assets` | ✓ |
| السائقون: إضافة بالجوال (يفعّل تطبيق السائق)، الحالة، الوثائق | `/workers` | ✓ |
| تنبيهات الوثائق المنتهية والقريبة من الانتهاء | `/documents` | ✓ |
| الخريطة الحية (Leaflet) مع مسار المناوبة | `/map` | ✓ |

| العملاء والمواقع | `/customers`, `/customers/[id]` | ✓ |
| العقود وقائمة الأسعار والتفعيل وحاسبة السعر | `/contracts`, `/contracts/[id]` | ✓ |
| الصيانة: المستحقة وأوامر العمل والخطط | `/maintenance`, `/maintenance/[id]` | ✓ |
| المصروفات واعتماد مطالبات السائقين | `/expenses` | ✓ |
| الفواتير: مسودة من المهام المراجَعة، بنود يدوية، إصدار، إلغاء، طباعة | `/invoices`, `/invoices/[id]` | ✓ |
| الذمم: الأعمار، الدفعات والعكس، كشف الحساب، COD، ميزان المراجعة | `/receivables` | ✓ |
| التقارير مع تصدير CSV | `/reports` | ✓ |
| الإعدادات: الفوترة، المستخدمون والأدوار، الفروع، سجل التدقيق | `/settings` | ✓ |
| بوابة العميل (طلباته فقط) | `/portal` | ✓ |

حساب السائق لا يدخل اللوحة (تطبيق الجوال لاحقًا)، وحساب العميل يرى البوابة فقط.

الخريطة تستخدم بلاط OpenStreetMap في التطوير فقط. للإنتاج يلزم مزوّد بلاط بترخيص تجاري عبر
`NEXT_PUBLIC_TILE_URL` و`NEXT_PUBLIC_TILE_ATTRIBUTION` [تحقق محلي].

## اختبار المتصفح

```bash
# مع تشغيل الخادم واللوحة
node e2e/smoke.mjs        # 24 خطوة: حساب بالبريد وكلمة المرور، ثم إلى الفاتورة والدفعة وCOD والبوابة. SHOTS_DIR=... للقطات
node e2e/delivery.mjs     # 11 خطوة: طلب توصيل، صفحة تتبع المستلم، الإسناد التلقائي، إثبات التسليم، الاستيراد، العمولات
node e2e/concrete.mjs     # 9 خطوات: طلب صب، الجدول الزمني، إسناد خلاطة، الاستثناءات، التذكرة، تعديل الكمية، تقرير الانتظار
node e2e/staffing.mjs     # 12 خطوة: طلب توريد، المرشحون، التعيين، التغطية، الحضور، البديل، كشف الساعات، اعتراض العميل وحله، الاعتماد، الفاتورة
node e2e/internal.mjs     # 10 خطوات: إدارة ومدير، طلب الموظفة من صفحتها، موافقة المدير، التخصيص والتسليم، لوحة المركبات، من كان يقود، الإرجاع، التكلفة على الإدارة، الاستثناءات، الإعدادات
node e2e/distribution.mjs # 6 خطوات: الشركة، كتالوج الأصناف، تخطيط مسار بثلاثة توقفات وقائمة التحميل، يوم السائق (تسليم ومرتجع ونقد ومحل مغلق)، المطابقة وتسوية العهدة بفرق مع ملاحظة، الاستثناءات وتقرير التوزيع
```
