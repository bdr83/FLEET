# منصة إدارة الأساطيل والعمليات الميدانية

منصة SaaS متعددة الشركات للنقل والأساطيل والعمليات الميدانية، تبدأ بالكويت ثم الخليج.
المستندات المرجعية: التحليل (A)، تجربة المستخدم (B)، المعمارية (C)، خطة البناء (D)، الجودة (E).

## الحالة: نواة الخادم (P0 إلى P8) ولوحة التحكم (W1 إلى W6) مكتملتان

| المكوّن | المسار | الحالة |
|---|---|---|
| مخطط قاعدة البيانات + RLS | `db/migrations` | جاهز ومختبر |
| اختبارات العزل والقيود والمحاسبة | `db/tests/run.sh` | 27 فحصًا |
| خدمة API (NestJS) | `apps/api` | P1: دخول OTP، إنشاء مؤسسة، الأدوار والنطاقات، الأعضاء، الشركات والفروع، سجل التدقيق. P2: المركبات، السائقون (مع دخول تطبيق السائق)، الوثائق وتنبيهات الانتهاء. P3: واجهات تطبيق السائق: المناوبات، استقبال المواقع، مهامي، المزامنة دون اتصال. P4: المهام بدورة حالاتها، الإسناد وإعادة الإسناد، لوحة التوزيع، إدارة المناوبات. P5: الخريطة الحية، إعادة عرض المسار، تقارير المهام والسائقين والأسطول مع تصدير CSV. P6: العملاء ومواقعهم، العقود وقوائم الأسعار، ربط المهمة بالعقد، بوابة العميل. P7: الصيانة الوقائية، أوامر العمل، المصروفات ومطالبات السائقين، تقارير التكلفة. P8: الفواتير من المهام، الدفعات والتخصيص، أعمار الذمم وكشف الحساب، دورة COD، الدفتر وميزان المراجعة |
| لوحة التحكم (Next.js) | `apps/web` | كل شاشات النواة بالعربية، مع بوابة العميل واختبار متصفح من 23 خطوة. التفاصيل في `apps/web/README.md` |
| تطبيق السائق (Flutter) | `apps/driver` | لم يبدأ (واجهاته في الخادم جاهزة تحت `/v1/driver`) |

## التشغيل محليًا

```bash
docker compose up -d
psql postgresql://admin:admin@localhost:5432/fleet -v app_rw_password="'devpass'" -f db/bootstrap.sql
DATABASE_URL=postgresql://admin:admin@localhost:5432/fleet ./db/migrate.sh
ADMIN_DATABASE_URL=postgresql://admin:admin@localhost:5432/fleet \
APP_DATABASE_URL=postgresql://app_rw:devpass@localhost:5432/fleet ./db/tests/run.sh

cd apps/api && npm ci
DATABASE_URL=postgresql://app_rw:devpass@localhost:5432/fleet npm test
```

## قواعد ثابتة

- كل جدول فيه `tenant_id` محمي بـ RLS، وCI يفشل إن وُجد جدول بدونه.
- كل مرجع بين جداول الشركات مفتاح مركّب `(tenant_id, id)`.
- الشركة تأتي من الـ token الموقّع فقط، لا من الرابط أو الطلب.
- كل استعلام على بيانات الشركات يمر عبر `DbService.withTenant()`.
- الدفتر وسجل الحالات وسجل التدقيق للإضافة فقط.
- التطبيق يتصل بدور `app_rw` الذي لا يملك الجداول ولا يتجاوز RLS.
- لا تُدمج ميزة إلى `main` دون نجاح CI ومراجعة.
